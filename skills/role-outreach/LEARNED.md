# Learned — role-outreach

Corrections this skill has earned in use. Read before running it; these override

- **2026-09-28** — Re-read a Gmail draft before changing it, because the operator may have edited it by hand since it was written, adding an opener or changing a word. Change only what they asked, by selecting the exact text range inside the Message Body and calling execCommand('insertText'), never by re-pasting the whole body.
- **2026-09-28** — For a reader outside the operator's field, name the algorithms instead of the acronyms (implicit Q-learning, not IQL). In a follow-up on a thread that already carries the resume, write 'My resume is in my previous email.' instead of attaching it again.
- **2026-09-28** — In a referral paragraph, replace a list of methods with the result they produced, give the closing 'I want' sentence one piece of evidence (a measured speedup backs 'faster'), and name a benchmark as a benchmark ('the X benchmark', not the bare name).
- **2026-09-29** — In Gmail compose, type the recipient with a trailing comma rather than Tab, so autocomplete cannot swap in another contact, then focus Subject and Body by JS (input[name=subjectbox], div[aria-label='Message Body']). The To field grows once a chip lands, so a coordinate click meant for Subject types into To.
- **2026-09-30** — People from X arrive in skills/role-sourcing/state/lists/x-leads.jsonl with a handle and the post that makes them relevant. An X handle is not an address: find the person's domain and run the collision check on it before choosing a channel, and treat a reply to their own post or a DM as a send that needs the operator's approval like any email.
- **2026-10-01** — When a fund's talent lead sends a student directory (portfolio companies that asked to meet students, each with new-grad plans and a named hiring contact), treat it as a warm email channel: save it under home/reference/vc-directories/ (contacts never go in a commit), screen and gate it as references/vc-directories.md says, and draft one email per company that names the directory and who shared it.
- **2026-10-04** — The Gmail connector's draft reads (get_draft, list_drafts) leave out attachments: a draft that read as bare there showed six PDFs in Gmail (2026-10-04). Before re-attaching files or calling a draft bare, open it in Chrome and read its '.pdf (NNK)' chips.
- **2026-10-04** — Fast path for a batch of drafts with files: create each with the Gmail connector's create_draft (HTML body), then in Chrome open its viewUrl under /mail/u/1/, expand the minimized compose by clicking its 'Compose: <subject>' heading, tag that compose's input[type=file] with an aria-label by script, find it, file_upload resume, paper and links page in that order, read the chips back, and Save & close (nine drafts on 2026-10-04).
- **2026-10-05** — A reply draft made with the Gmail connector (create_draft with replyToMessageId) and then opened in Gmail's thread view, say to attach a resume, gets every link in its body rewritten to a google.com/url redirect, and that is what saves and sends. Before leaving the draft, set each editor link's href back to its q parameter, drop data-saferedirecturl, and type-and-delete a space so Gmail saves it; check with get_draft. Drafts composed in the full-page compose window (view=cm) keep their links. Attachments never show in get_draft, so confirm them by the chips in the Drafts list (2026-10-05).
