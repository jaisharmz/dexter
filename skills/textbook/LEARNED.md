# Learned — textbook

Corrections this skill has earned in use. Read before running it; these override
`SKILL.md`. Protocol: `kernel/skill-learning.md`.

- **2026-10-20** — Sampler figures (reverse SDE vs ODE, Langevin): 400 particles cannot resolve step-count effects, since W1 of 400 exact draws ranges 0.04 to 0.18 across seeds. Use 2000+ particles, show the exact-draws median as a readout, and drive every step count with one Brownian path (step counts that divide the finest grid), so readouts move smoothly with N. Unadjusted Langevin on a quartic well explodes from the tails of an N(0, 1) start (h = 0.05, step 6): start chains at 0 or a mode.
- **2026-10-21** — Headless figure screenshots come back blank about a third of the time because the IntersectionObserver never fires under --virtual-time-budget, and rerunning the same command often fails again. Capture each figure alone with a fresh --user-data-dir, inject a scroll nudge into the scratch copy (setTimeout(()=>{scrollTo(0,2);scrollTo(0,0)},150)), check the stage region's pixel standard deviation, and retry until it is nonzero; a DOM dump with no <canvas> and no console error confirms a capture flake and rules out a figure bug.
- **2026-10-21** — Before deepening a book that already shipped, run the math audit first: two fresh agents with an adversarial brief, the book split in half, each finding checked by a derivation or a script and marked confirmed or suspected. On Fundamental Ideas v2 they found 27 problems, among them a whole-trajectory map that only shifted entries (Proposition 4.3) and a 'converge to an equilibrium' that holds only for averages. Fix the confirmed ones before adding anything, and start each chapter's figure agent as soon as that chapter's fixes are in.
- **2026-10-21** — Inline math wider than about 300 px overflows at 375 px inside the indented boxes (views, joins, folded solutions). Promote any inline formula with two relations, a sum, or an integral to a display eqbox, and measure at 375 px by listing mjx-container elements whose right edge passes the viewport.
- **2026-10-21** — Place figures with <!--fig:ID@C--> and cite them with <!--ref:ID-->, never by number or by 'the second figure': a revision that adds figures renumbers every later one. Keep square brackets out of captions that also hold a markdown link, because md_inline folds the bracketed text into the link.
- **2026-10-21** — The Browser pane is often hidden while a session works, and a hidden pane never fires IntersectionObserver, so every figure stays unset and screenshots come back stale. To check the whole build, serve a temporary copy with an IntersectionObserver shim that reports every figure visible, then count fperr, canvases with no ink, empty readouts, mjx-merror, and scrollWidth at 1100 and 375 px in both color schemes, and delete the copy. For headless Chrome captures, a virtual-time budget of 12000 avoids most blank captures.
