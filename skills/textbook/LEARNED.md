# Learned — textbook

Corrections this skill has earned in use. Read before running it; these override
`SKILL.md`. Protocol: `kernel/skill-learning.md`.

- **2026-10-20** — Sampler figures (reverse SDE vs ODE, Langevin): 400 particles cannot resolve step-count effects, since W1 of 400 exact draws ranges 0.04 to 0.18 across seeds. Use 2000+ particles, show the exact-draws median as a readout, and drive every step count with one Brownian path (step counts that divide the finest grid), so readouts move smoothly with N. Unadjusted Langevin on a quartic well explodes from the tails of an N(0, 1) start (h = 0.05, step 6): start chains at 0 or a mode.
- **2026-10-21** — Headless figure screenshots come back blank about a third of the time because the IntersectionObserver never fires under --virtual-time-budget, and rerunning the same command often fails again. Capture each figure alone with a fresh --user-data-dir, inject a scroll nudge into the scratch copy (setTimeout(()=>{scrollTo(0,2);scrollTo(0,0)},150)), check the stage region's pixel standard deviation, and retry until it is nonzero; a DOM dump with no <canvas> and no console error confirms a capture flake and rules out a figure bug.
- **2026-10-21** — Before deepening a book that already shipped, run the math audit first: two fresh agents with an adversarial brief, the book split in half, each finding checked by a derivation or a script and marked confirmed or suspected. On Fundamental Ideas v2 they found 27 problems, among them a whole-trajectory map that only shifted entries (Proposition 4.3) and a 'converge to an equilibrium' that holds only for averages. Fix the confirmed ones before adding anything, and start each chapter's figure agent as soon as that chapter's fixes are in.
- **2026-10-21** — Inline math wider than about 300 px overflows at 375 px inside the indented boxes (views, joins, folded solutions). Promote any inline formula with two relations, a sum, or an integral to a display eqbox, and measure at 375 px by listing mjx-container elements whose right edge passes the viewport.
- **2026-10-21** — Place figures with <!--fig:ID@C--> and cite them with <!--ref:ID-->, never by number or by 'the second figure': a revision that adds figures renumbers every later one. Keep square brackets out of captions that also hold a markdown link, because md_inline folds the bracketed text into the link.
- **2026-10-21** — The Browser pane is often hidden while a session works, and a hidden pane never fires IntersectionObserver, so every figure stays unset and screenshots come back stale. To check the whole build, serve a temporary copy with an IntersectionObserver shim that reports every figure visible, then count fperr, canvases with no ink, empty readouts, mjx-merror, and scrollWidth at 1100 and 375 px in both color schemes, and delete the copy. For headless Chrome captures, a virtual-time budget of 12000 avoids most blank captures.
- **2026-10-21** — When a script splices TeX into shell.html, use raw strings (r'''...'''): a plain Python string turned \theta into a tab plus 'heta' in four places, and the build stayed silent. After any scripted edit, grep the file for control characters.
- **2026-10-21** — When a figure's layout depends on a toggle (a seg that adds a panel or switches the source), its canvas height can depend on the toggle too; refit it with draw(true) on every toggle, or the new layout clips at the old height.
- **2026-10-21** — For headless captures of figures with play loops, the IntersectionObserver shim alone is not enough: also replace requestAnimationFrame with a 16 ms setTimeout in the scratch copy. With both, every capture of the adjoint figures came back drawn, against about one in three without.
- **2026-10-21** — Round-off readouts (a gap of 1e-15 between two solvers) differ between node and Chrome, so a caption should state them as bounds ('below 1e-14'), never as the exact value the node test printed.
- **2026-10-21** — When a caption number comes from badly conditioned linear algebra (EDMD by G^+A at high degree), node and Chrome can disagree in the second digit. Solve by QR or another stable method, and compare the built page's readouts against the node test before trusting the caption.
- **2026-10-21** — For the 375 px check, do not trust the Browser pane's viewport emulation while the pane is hidden: innerWidth flipped between 375 and 626 between calls. Serve a wrapper page with iframes at 375 and 1100 px, one light copy and one dark copy (a script that sets data-theme=dark), each with the IntersectionObserver shim, and run the checks inside each frame's document. One load checks all four combinations.
- **2026-10-22** — A headless capture loop that waits for the PNG to appear must delete the previous PNG first, or it returns the stale image for a round. And a histogram of a discrete exact law (a Beta-binomial at draw t) looks jagged unless the number of atoms divides evenly into the bins; pick the default t or the bin count so it does.
- **2026-10-22** — A figure whose caption compares a Monte Carlo frequency with an exact bound (Ville's alpha) needs enough paths that the standard error is well under the gap: with 200 paths a 0.045 probability has error 0.015 and one seed reads as a breach of the bound. Simulate thousands, draw a few hundred, and show the exact value beside the simulated one.
- **2026-10-22** — A first-principles pass works as separate fresh auditors (three chapters each) who read a guide to the operator's own writing and return exact old/new patches, applied inside each patch's chapter only; then a second round of fresh verifiers rechecks every number the patches added. On Fundamental Ideas v6, 173 patches applied with no skips, and the verifiers still found 4 wrong claims and about 30 imprecise ones in the new text (a toy's loss misdescribed, an error rounded wrong, a Lipschitz constant of 0). Never ship rewrites without the second round.
