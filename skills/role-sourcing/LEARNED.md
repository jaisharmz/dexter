# Learned — role-sourcing

Corrections this skill has earned in use. Read before running it; these override
`SKILL.md`. Protocol: `kernel/skill-learning.md`.

- **2026-09-28** — Never credit the operator with a library their work only builds on. Name whose library it is and say exactly which part is theirs. A wrong ownership claim spreads into every thesis that reuses the artifact, so correct it at the source in `config/persona.md`.
- **2026-09-28** — Read job boards through the ATS JSON feeds (curl) and company pages through WebFetch before spending any WebSearch: the 200-call WebSearch budget is shared by every agent in the session, and a six-batch parallel sweep exhausted it mid-run, leaving LinkedIn snippet reads and funding checks undone. Save WebSearch for LinkedIn snippets and funding news.
- **2026-09-28** — Ask the operator for the LinkedIn People-tab read on every company before handing over a list to apply to. A sweep once skipped the read to save search budget and the operator asked for it anyway: the read dropped two companies on low hit rates and surfaced a warm path to a co-founder. It costs the operator one page load per company, in their own signed-in browser, and costs no WebSearch, so the budget is never a reason to skip it.
